# Face Recognition Attendance System

Welcome to the Face Recognition Attendance System project. This system is designed to simplify the process of marking attendance using face recognition technology. It utilizes Python, Flask, and Pyrebase for user authentication and data storage.

## Demo

Check out the live demo of the project [here](https://www.vrnitsolution.tech/projects/9ddddcca-a8c7-426e-9c64-f0d7f11c5635).

## Features

- **User Authentication**: Secure login using Firebase authentication.
- **Face Detection and Recognition**: Utilizes OpenCV for face detection and recognition.
- **Student Data Management**: Manage student information and attendance records.
- **Real-time Webcam Preview**: Provides a live preview for face recognition through the webcam.

## Requirements

Make sure you have the following installed on your system:

- Python 3.x
- Flask
- OpenCV
- Pyrebase
- win32com (for Windows text-to-speech)
